Option 3: Manual Installation

  2. Rename to kolumn.exe and move to a directory in your PATH
  3. Or add the download location to your PATH environment variable
  4. Open a new terminal and run kolumn version to verify

WSL Setup Notes

  1. Ensure WSL 2 is installed: wsl --install
  2. Open your WSL terminal (Ubuntu, Debian, etc.)
  3. Run the install command above
  4. Add to PATH if needed: export PATH="$HOME/.local/bin:$PATH"

WSL provides the best Linux compatibility on Windows for development workflows.

Why Choose Kolumn?

DB

Unified Database Management

Support for PostgreSQL, MySQL, SQLite, MongoDB, DynamoDB, BigQuery, Snowflake, and more through a single interface.

SD

Schema Drift Detection

Automatically detect and track schema changes across environments with Git-style versioning and rollback capabilities.

ETL

ETL/Streaming Integration

Native support for dbt, Airbyte, Fivetran, Kafka, Kinesis, and other modern data pipeline tools.

IaC

Infrastructure as Code

Terraform-style HCL configuration for your entire data stack with plan, apply, and destroy workflows.

SEC

Enterprise Security

Role-based access control, audit logging, and compliance features for enterprise-grade data governance.

AI

AI-Powered Analytics

Built-in AI assistance for optimization recommendations, performance insights, and predictive maintenance.
